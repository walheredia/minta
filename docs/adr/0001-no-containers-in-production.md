# Production runs without containers, on the existing shared droplet

Minta deploys to a DigitalOcean droplet that already runs Laravel sites under Apache and has PM2 installed from a prior, now-retired Node app. Rather than introducing Docker Compose in production, CI builds the NestJS backend and Next.js frontend, ships the artifacts over SSH, and runs them as PM2-managed processes (PM2 itself supervised by systemd via `pm2 startup`) behind a new Apache vhost for `minta.appcont.com.ar` that reverse-proxies `/` to Next.js and `/api` to NestJS. Docker is used locally only, to run MySQL for development; production MySQL runs natively on the same droplet. This avoids running a second web server/process model alongside the Apache + PHP stack already in place, at the cost of local dev and production not being identical environments.
