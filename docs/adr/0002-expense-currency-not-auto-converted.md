# Expenses are recorded in their real currency, never auto-converted

Each **Expense** is stored in the **Currency** that actually moved (ARS or USD) — a USD-denominated subscription charged to an ARS card is recorded in ARS for the amount actually charged, not derived from a USD face value. Totals are kept and shown separately per currency, with no summing across currencies. A user-configured **Reference Exchange Rate** (plus the impuesto PAIS percentage) renders an estimated ARS-equivalent next to USD totals for display only — it is never stored on or used to compute the Expense itself. This keeps bookkeeping exactly matching what left the user's pocket, and keeps the data model ready for a planned LLM-based import of credit card statements, which will read amounts directly off the statement line rather than inferring a conversion.
